# vinewoodsign

Made with FiveMRides Sign Studio.

## Install

1. Put the `vinewoodsign` folder in your server `resources` folder.
2. Add `ensure vinewoodsign` to your `server.cfg`.
3. Restart the server (a map resource needs a full restart, players reconnect).

## Replaces the Vinewood sign

This resource hides the original sign (letters, far models, night glow, collision) and puts the new one in its place.
Run only ONE sign resource that replaces the Vinewood sign at a time.
It also ships edited copies of 4 collision files of the hill (`ch2_03_1`, `ch2_03_7`, `hi@ch2_03_2`, `hi@ch2_03_7`):
another map that edits the same hill collision would conflict with it.

## Game version

GTA V Legacy (FiveM): tested. GTA V Enhanced: not tested yet.
