RTX Shell Creator - your own textures

Put your own wall, floor and ceiling textures here, as many as you like (up to 200):

  brick_mine.png, tiles-blue.png, oak_dark.png ...

- Square PNG, 512 x 512 or 1024 x 1024 pixels.
- File names may use letters, numbers, _ and - only.
- One picture is one metre of wall or floor and it repeats, so make it seamless.
- Restart rtx_shellcreator after adding or changing a file.
- They show up in the paint palette under "Own textures". One house can use 6 of them at the same time.
- The editor shows the file name. A nicer name can be set in config.lua (Config.Shells.customtextures, by file name).
- Built shells and MLOs bake them in, so players do not need these files.
